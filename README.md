# 📡 Microwave Link Project

Proyecto académico para el diseño y análisis de una red de enlaces de microondas utilizando **Pathloss 5** y **Radio Mobile**.

Este repositorio contiene los archivos de configuración, perfiles de enlace, equipos de radio, antenas y datos de terreno utilizados durante el desarrollo del proyecto.

---

## 📁 Estructura del repositorio

```text

│
├── pathloss_files/
```

---

## 🛰️ Pathloss 5

La carpeta `pathloss_files` contiene los archivos utilizados para el diseño y análisis de los enlaces en **Pathloss 5**.

### Contenido

* `antenas_asd/` — archivos de antenas `.asd`
* `radios_rsd/` — archivos de radios `.rsd`
* `red_y_enlaces/` — archivos de la red y perfiles de transmisión
* `ubicacion_srtm_pathloss.png` — referencia para la ubicación de los archivos SRTM

Dentro de `red_y_enlaces` se encuentran archivos como:

* `.gr5` — archivo principal de la red
* `.pl5` — perfiles individuales de los enlaces
* `.p5g` — configuración utilizada en Pathloss
* `.ndx` — índice relacionado con los datos de terreno

---

## 🌐 Radio Mobile

La carpeta `radioMobile_files` contiene los archivos utilizados para el diseño y simulación de la red mediante **Radio Mobile**.

Incluye archivos de:

* Red
* Mapas
* Información geográfica
* Ubicación de los enlaces

---

## 🗺️ SRTM FILES

Contiene información e indicaciones relacionadas con los archivos **SRTM (Shuttle Radar Topography Mission)** utilizados para trabajar con datos de elevación del terreno.

Estos datos permiten generar los perfiles topográficos necesarios para analizar la línea de vista y las condiciones de propagación de los enlaces.
